# LIX TV

Aplicativo Android TV Box para reprodução de canais públicos do projeto IPTV-org. Catálogo pode conter streams indisponíveis; não inclui conteúdos privados do UniTV.

## Compilar
Na aba **Actions**, execute **Compilar APK Android** (ou aguarde compilação no push). Baixe o artifact `LIX-TV-debug-apk` contendo `app-debug.apk`. O APK necessita teste em aparelho real.

## Recursos
Lista de canais brasileiros, busca, player Media3, navegação com controle remoto e favoritos. Versão inicial v0.4 experimental.
